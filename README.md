# jillanneyoussef.com

This is my personal site. It's half work portfolio, half passion project.

The portfolio side is for recruiters: my co-ops, my projects and my resume. The other side is for getting to know me outside of work. There's a little pixel-art world you can walk around in, and it's full of easter eggs. I add one whenever something feels meaningful to me, so if you find something random, it's probably there for a reason (and yes, that's my cat Moe).

I'm treating this as an archive of my life since I started university, and I want to keep adding to it for as long as I can.

Always open to feedback :)

## how it's built

Just HTML, CSS and JavaScript, no framework or build step. Hosted on GitHub Pages.

- `index.html`: welcome screen, portfolio, project write-ups
- `world.js`: the pixel world
- `img/`, `vid/`, `sfx/`: pictures, videos and sounds
