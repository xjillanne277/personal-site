# jillanneyoussef.com

hi, I'm Jillanne. I'm a mechanical engineering student at the University of Waterloo (3B right now) and this is my personal site.

I like taking an idea from a rough sketch to something that can actually be built: prototyping, CAD, testing it until it breaks, then making it easier to manufacture. I've done co-ops at Google, Level Home, Tesla, Geotab, Valbruna and Evercloak, and right now I'm on the CHANGE design team building a low-cost pressure-relief system for wheelchair users.

I'm looking for a Summer 2027 internship, so if you're here from my resume, hi again :)

## what's on the site

- a portfolio with write-ups of my projects (the Level test fixture and the RGBW LED controller I designed are the big ones)
- a little pixel-art game where you can walk around, read about my work, take a boat across the river, and drive a car. my cat Moe is in it too
- my resume

## how it's built

No framework and no build step, just HTML, CSS and JavaScript. It's hosted on GitHub Pages.

- `index.html`: welcome screen, portfolio, project write-ups
- `world.js`: the game
- `img/`, `vid/`, `sfx/`: pictures, videos and sound effects

If you want to reach me, the email button on the site copies my address.
